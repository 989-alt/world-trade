# 0. Reference image (style and camera only)
Open the file ./assets/_ref/ref-ship-style.png — a crop of the approved game world map showing a harbor diorama. Draw the ship below in exactly this art style, camera angle and lighting so it looks like it belongs on that map.
# 1. Scene
A sprite sheet of one cute rounded cargo ship with a navy hull, a white bridge at the stern and stacked red, blue and yellow containers, drawn in eight headings in two rows of four equal cells on a flat solid magenta (#FF00FF) background: top row heading north, northeast, east, southeast; bottom row heading south, southwest, west, northwest. Same ship, same scale (about 70% of the cell width) in every cell, centered, a short soft white foam wake trailing behind each, a small soft shadow on the water side as if resting on the map's sea. Nothing else in the cells.
# 2. Camera
The same high three-quarter top-down view as the reference map (not straight top-down): hull sides and bridge walls visible, deck foreshortened, consistent across all eight headings.
# 3. Lighting
Bright midday sun from upper left, soft ambient occlusion, crisp but soft-edged shadow, matching the reference.
# 4. Color grading
Sea #3FA7E6 is NOT used in the background (magenta only). Hull navy #1B2A41, containers red #E04B3A, blue #2F6DB5, yellow #F2C14E, orange accent #F2994A. Around 5600K, clean and bright.
# 5. Texture/Medium
Smooth stylized 3D render look with soft shading, rounded forms, subtle clay-like surface, polished game-art finish, matching the reference exactly.
